# 策划与质检

## 策划输出模板

在成图前按以下顺序输出，信息简洁但足以让用户确认：

1. **推荐选题**：主题名称。
2. **一句核心结论**：全组最希望读者记住的话。
3. **内容形态**：概念词解、知识片段、对比图解或流程故事，并说明一句理由。
4. **事实核验**：列出 3–5 个将进入图片的关键事实，每项附最相关的一手或权威来源链接；标明仍存在的边界或不确定性。
5. **页数建议**：明确总页数，不少于 4 页。
6. **逐页分镜**：使用表格，包含下列列项：
   - 页码与页面职责
   - 单页核心结论
   - 顶部或底部精确文案（核心结论 + 2–3 条短补充）
   - 故事动作
   - 画面重点与主要道具
   - 小哈是否出现及叙事作用
7. **配色**：给出主色、辅助色、强调色及选择理由。
8. **固定角标**：确认 `2026 / AI / {{关键词}}`，其中关键词不超过 4 个字符。

策划结尾只问：“是否按这版选题、页数和分镜生成？”不要同时追加第二个问题。

## 文案检查

- 每页只有一个核心结论。
- 每条补充尽量控制在一行可读长度，不写论文式长句。
- 技术术语第一次出现时给出人话解释；不滥用英文缩写。
- 不用“绝对不会”“完全取代”“百分百正确”等绝对化表述。
- 数据、版本、产品行为与时间敏感信息和核验来源一致。
- 结论准确优先于俏皮；类比要注明边界，不能让读者形成错误机制理解。

## 成图逐页质检

按下表逐项核对，任一硬性项失败都要修复后再交付：

| 类别 | 通过标准 |
|---|---|
| 文件 | 每页为独立图片，数量与确认页数一致，顺序明确 |
| 比例 | 每张严格为 3:4 竖版 |
| 文字 | 中文逐字正确、无乱码、字号可读；正文只在顶部或底部 |
| 信息 | 每页一个核心结论，含 2–3 条短补充，且与核验事实一致 |
| 封面 | 大标题居中，主题词为第一视觉焦点，信息层级清晰 |
| 角标 | 每页都有 `2026`、`AI` 和已确认关键词，且没有用户未提供的署名或品牌信息 |
| 小哈 | 需要出现的页面上，耳朵、黑色头顶与背部、白鼻梁和口鼻、白色胸腹与四爪一致，无奶牛斑 |
| 角色比例 | 头、耳、肩胸、躯干和四肢连接自然；无大头小身体、悬空手掌、多余爪子或被角落压缩的完整身体 |
| 画法 | 仅用粗黑轮廓、扁平色块和少量网点；无写实毛发、真实眼球、软阴影、体积光、摄影或 3D 质感 |
| 统一性 | 全组配色、线条、字体气质一致；动作、道具、场景不机械重复 |
| 叙事 | 封面提出主题，中段完成理解，结尾总结并提醒适用场景或避坑 |
| 原创性 | 未复刻参考图的原文、品牌、人物、标志或具体构图 |

## 最终交付

只按页码顺序展示最终图片。不要添加正文、来源、创作说明、策划回顾或“已完成”等文字；只有用户明确要求时才输出额外内容。
